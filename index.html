01 — 참여 동의

온라인 강의 집중도 연구

참여해 주셔서 감사합니다. 총 소요 시간은 약 20분입니다.

연구 목적

온라인 강의를 시청하는 동안의 집중 상태를 얼굴과 상체 자세로 판단할 수 있는지 연구합니다.

수집하는 정보

  • 웹캠 영상 (얼굴 및 상체, 약 15분)
  • 강의 중 응답 — 집중 상태 자기보고, 간단한 곱셈 문제의 답과 응답 시간
  • 강의마다 내용 확인 문제 2개의 응답
  • 휴대폰 번호 — 사례 지급과 제출 파일 확인 용도

데이터 처리

  • 영상은 참가자 본인의 컴퓨터에만 저장되며 자동으로 전송되지 않습니다.
  • 연구팀에 직접 전달한 파일만 분석에 사용됩니다.
  • 실명·학번은 수집하지 않습니다. 휴대폰 번호는 사례 지급과 파일 확인에만 쓰이며, 지급이 끝나면 삭제합니다.
  • 연구 결과를 발표할 때는 개인을 알아볼 수 있는 정보를 일절 포함하지 않습니다.
  • 연구 종료 후 원본 영상은 삭제하고, 분석에는 영상에서 추출한 좌표 정보만 사용합니다.

참여 조건

  • 참여는 자발적이며 언제든 중단할 수 있고, 중단해도 어떠한 불이익도 없습니다.
  • 중단 시 그때까지 수집된 데이터는 폐기됩니다.
  • 문의: (담당자 연락처)
사례 지급과 파일 확인에만 사용됩니다.

03 — 진행 순서

이렇게 진행됩니다

두 파트로 나뉘며, 파트마다 5분짜리 강의를 하나씩 봅니다. 파트 순서는 사람마다 다릅니다.

두 파트

  • 계산 파트 — 곱셈 문제 10개를 먼저 풀고, 이어서 바로 강의를 봅니다. 강의 중에도 같은 문제가 가끔 나타납니다. 강의가 끝나면 곱셈 문제 10개를 더 풉니다.
  • 딩 소리 파트 — 40초 연습 후 이어서 바로 강의를 봅니다. 강의 중 "딩" 소리가 나면 질문에 답합니다.
  • 각 강의가 끝나면 내용 문제 2개를 풉니다.
  • 파트를 시작하기 직전에 자세한 방법을 다시 안내합니다.
첫 파트를 시작하면 녹화가 시작됩니다. 끝날 때까지 브라우저 탭을 닫거나 새로고침하지 마세요. 데이터가 모두 사라집니다.
